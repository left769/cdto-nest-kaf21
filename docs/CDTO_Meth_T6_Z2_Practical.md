# Інструменти штучного інтелекту для управлінських задач підрозділу ЦТ

*Тема 6: Практичні цифрові інструменти та технології штучного інтелекту · Заняття 2*

## 1. Огляд актуальних ШІ-інструментів для задач підрозділу ЦТ

### 1.1. Класи ШІ-інструментів

| Клас | Що робить / приклад задачі |
| --- | --- |
| Мовні моделі (LLM) | Текст: чернетки документів, звітів, листів, узагальнення. |
| Аналітичні асистенти | Аналіз таблиць, пошук закономірностей, побудова графіків. |
| Інструменти транскрипції | Розшифровка нарад, протоколи. |
| Генерація зображень/схем | Ілюстрації, схеми процесів (для презентацій). |
| Асистенти в застосунках | Вбудовані помічники в офісних/проєктних інструментах. |

### 1.2. Принцип вибору

Інструмент обирають за задачею та — критично — за дозволеністю для роботи в ЗСУ. Багато популярних ШІ-сервісів є зовнішніми (хмарними), тож для службової інформації вони недопустимі. Використовують лише дозволені інструменти на дозволених даних.

**Типові помилки:**

- використання неавторизованих зовнішніх ШІ для службових задач;
- вибір інструмента без урахування ЗІ;
- сприйняття ШІ як «джерела істини».

### 1.3. ШІ в щоденній роботі офіцера ЦТ

Найбільшу користь ШІ дає в рутинних, «чорнових» задачах, де людині коштовно починати «з чистого аркуша»: перша структура документа, узагальнення довгого тексту, варіанти формулювань, ідеї для рішення. У задачах, що потребують відповідальності й точності (остаточні рішення, офіційні висновки, робота зі службовою інформацією), ШІ або не застосовують, або використовують лише як чернетківця з обов’язковою перевіркою.

*Проміжний висновок: ШІ-інструменти різноманітні; вибір визначається задачею й суворою вимогою дозволеності для ЗСУ.*

## 2. Застосування ШІ: аналіз даних, підготовка звітів, генерація документів і комунікацій

### 2.1. Аналіз даних

ШІ пришвидшує аналіз: узагальнення великих обсягів тексту, пошук закономірностей у даних, чернетка висновків. Але результат — це чернетка для перевірки, а не готовий висновок: ШІ може помилятися й «вигадувати» (галюцинації).

### 2.2. Підготовка звітів і документів

ШІ добре готує чернетки: структуру звіту, перше формулювання аналітичної записки, типові документи. Людина доопрацьовує, перевіряє факти й адаптує під контекст. Це економить час на «чистому аркуші».

### 2.3. Комунікації

ШІ допомагає скласти чернетку листа, переформулювати текст під аудиторію, підготувати відповіді на типові звернення. Остаточне рішення про зміст і тон — за людиною.

### 2.4. Головний принцип

ШІ — помічник-чернетківець, а не автор рішення. Відповідальність за фінальний результат завжди на офіцері. Кожен факт, цифру й формулювання перевіряють.

*Приклад. ШІ склав чернетку звіту за 2 хвилини; офіцер перевірив цифри, виправив висновок і додав контекст — час зекономлено, якість забезпечено.*

**Приклади доречних задач для ШІ в підрозділі ЦТ:**

| Задача | Роль ШІ (чернетківець) |
| --- | --- |
| Тижневий статус-звіт | Чернетка структури й формулювань — людина звіряє факти. |
| Узагальнення нарад | Стислий конспект — людина перевіряє точність. |
| Чернетка ТЗ / записки | Первинна структура — людина наповнює й перевіряє. |
| Переформулювання під аудиторію | Варіанти тексту — людина обирає й адаптує. |

**Типові помилки:**

- використання результату ШІ без перевірки;
- довіра до «фактів» і цифр від ШІ без звірки;
- делегування ШІ рішення, а не чернетки.

*Проміжний висновок: ШІ пришвидшує аналіз, звіти й комунікації як чернетківець; перевірка й відповідальність — завжди за людиною.*

## 3. Ефективний промпт-інжиніринг для управлінських задач

### 3.1. Що таке промпт

Промпт — запит до ШІ. Якість результату прямо залежить від якості промпта: розмитий запит дає розмиту відповідь. Промпт-інжиніринг — уміння формулювати запити, що дають корисний результат.

### 3.2. Структура хорошого промпта

| Елемент | Приклад |
| --- | --- |
| Роль / контекст | «Ти — аналітик підрозділу ЦТ». |
| Завдання | «Склади структуру аналітичної записки…». |
| Вхідні дані | «…на основі таких даних: …». |
| Формат результату | «…у вигляді 6 розділів із висновком на початку». |
| Обмеження | «Стисло, офіційним стилем, без вигаданих фактів». |

### 3.3. Принципи

- бути конкретним (що саме, у якому форматі);
- давати контекст і приклади;
- розбивати складну задачу на кроки;
- ітерувати — уточнювати промпт за результатом;
- просити ШІ не вигадувати, а зазначати невпевненість.

*Приклад. Слабкий промпт: «Напиши звіт». Сильний: «Склади чернетку тижневого статус-звіту про впровадження ІКС за структурою: статус, прогрес, блокери, потрібні рішення; стисло, офіційно».*

**Типові помилки:**

- розмитий промпт без контексту й формату;
- складна задача одним промптом без декомпозиції;
- відсутність ітерації й уточнення.

### 3.4. Розбір промптів «до / після»

| Слабкий промпт | Сильний промпт |
| --- | --- |
| «Проаналізуй дані». | «Ти — аналітик ЦТ. Виділи 3 ключові тенденції в цих даних про adoption і поясни ймовірні причини. Стисло». |
| «Напиши лист». | «Склади офіційний лист начальнику підрозділу з проханням виділити 1 особу на пілот; тон поважний, аргумент — економія часу». |
| «Зроби презентацію». | «Запропонуй структуру 7-хв презентації проєкту за пірамідою Мінто: гачок, головна думка, 3 аргументи, заклик». |

*Проміжний висновок: якість результату ШІ визначається якістю промпта — конкретність, контекст, формат і ітерація.*

## 4. Обмеження та ризики використання ШІ з інформацією обмеженого доступу

### 4.1. Головне обмеження

Категорично заборонено вводити службову інформацію та інформацію з обмеженим доступом (ДСК, таємно) у неавторизовані (зовнішні, хмарні) ШІ-сервіси. Введені дані можуть зберігатися, оброблятися й потенційно розкриватися — це витік інформації з усіма наслідками.

### 4.2. Інші ризики

| Ризик | Суть |
| --- | --- |
| Витік інформації | Службові дані потрапляють у зовнішній сервіс. |
| Галюцинації | ШІ впевнено видає хибні факти й цифри. |
| Упередженість | Викривлення через дані навчання. |
| Застарілість | Модель не знає найновіших даних. |
| Надмірна довіра | Ухвалення рішень без перевірки. |

### 4.3. Правила безпечного використання

- лише дозволені інструменти на дозволених (неслужбових/знеособлених) даних;
- ніколи не вводити інформацію обмеженого доступу в зовнішні ШІ;
- перевіряти кожен факт і цифру перед використанням;
- узгоджувати використання ШІ з вимогами ЗІ й керівництвом;
- пам’ятати: відповідальність за результат — на людині.

**Типові помилки:**

- введення службової інформації у зовнішній ШІ;
- використання результату без перевірки фактів;
- ігнорування вимог ЗІ «бо швидше».

*Проміжний висновок: головне правило — інформацію обмеженого доступу не вводять у неавторизовані ШІ; результат завжди перевіряють.*

## 5. Практична вправа: розв’язання управлінських задач із використанням ШІ-інструментів

**Мета вправи:** слухачі застосовують ШІ для типових управлінських задач (чернетка звіту, узагальнення, структура документа) на відкритих даних, відпрацьовуючи промпти й перевірку результату.

**Вихідні дані:** неслужбові навчальні дані; дозволений ШІ-інструмент; шаблони промптів (Додаток 1).

**Форма роботи:** у парах, з презентацією результатів і розбором промптів.

### Порядок виконання

1. Скласти промпт для чернетки статус-звіту; отримати й оцінити результат — 15 хв.
2. Уточнити промпт (ітерація) для покращення результату — 10 хв.
3. Перевірити результат: факти, формулювання, відповідність задачі — 15 хв.
4. Презентація 2–3 результатів із розбором вдалих і слабких промптів — 10 хв.

### Еталонне проходження (зразок для викладача)

**Промпт.** «Ти — аналітик ЦТ. Склади чернетку тижневого статус-звіту про впровадження ІКС за структурою: статус (світлофор), прогрес, блокери, потрібні рішення. Стисло, офіційно, без вигаданих фактів».

**Ітерація.** Додати: «зроби блок ‘потрібні рішення’ конкретнішим».

**Перевірка.** Звірити, що ШІ не додав вигаданих цифр; адаптувати під реальний контекст.

### Методичні вказівки викладачу

Викладач стежить, щоб слухачі: (1) НЕ вводили жодної службової інформації; (2) складали структуровані промпти; (3) перевіряли результат, а не приймали «як є». Наголошує, що вправа — на відкритих даних, і переносить принцип ЗІ на реальну роботу.

## Контрольні питання

1. Які класи ШІ-інструментів застосовні в задачах підрозділу ЦТ?
2. Для яких задач доречний ШІ і чому результат — це чернетка?
3. Опишіть структуру ефективного промпта.
4. Яке головне обмеження використання ШІ з інформацією обмеженого доступу?
5. Назвіть ризики ШІ й правила безпечного використання.

## Завдання для закріплення

1. Скласти бібліотеку промптів для типових задач свого підрозділу (на відкритих даних).
2. Підготувати з допомогою ШІ чернетку документа й доопрацювати її, зафіксувавши, що виправили.
3. Скласти пам’ятку правил безпечного використання ШІ для підрозділу.

## Додаток 1. Шаблони промптів для управлінських задач

| Задача | Шаблон промпта |
| --- | --- |
| Чернетка звіту | «Ти — аналітик ЦТ. Склади [тип звіту] за структурою […]. Стисло, офіційно, без вигаданих фактів». |
| Узагальнення тексту | «Стисло узагальни цей текст у [N] тезах, збережи ключові факти». |
| Структура документа | «Запропонуй структуру [документа] для [мета], з поясненням кожного розділу». |
| Переформулювання | «Переформулюй цей текст для [аудиторія], простою мовою, зберігши зміст». |

## Додаток 2. Правила безпечного використання ШІ (пам’ятка)

- НІКОЛИ не вводити службову інформацію та інформацію обмеженого доступу у зовнішні ШІ.
- Використовувати лише дозволені інструменти на дозволених даних.
- Перевіряти кожен факт, цифру й формулювання від ШІ.
- Пам’ятати про галюцинації: ШІ може впевнено помилятися.
- Узгоджувати використання ШІ з вимогами ЗІ й керівництвом.
- Відповідальність за результат — завжди на людині.

## Додаток 3. Критерії оцінювання роботи з ШІ

| Критерій | Бали | Орієнтир |
| --- | --- | --- |
| Якість промпта (конкретність, формат) | 0–3 | Структурований промпт. |
| Ітерація та покращення | 0–2 | Уточнення за результатом. |
| Перевірка результату | 0–3 | Факти звірено, не «як є». |
| Дотримання правил ЗІ | 0–2 | Жодної службової інформації. |
| Разом | 0–10 | 9–10 «відмінно»; 7–8 «добре»; 5–6 «задовільно». |

## Додаток 4. Глосарій ключових термінів

- **ШІ (штучний інтелект) — **системи, здатні виконувати задачі, що потребують «інтелекту».
- **LLM (мовна модель) — **ШІ для роботи з текстом.
- **Промпт — **запит до ШІ.
- **Промпт-інжиніринг — **уміння формулювати ефективні запити.
- **Галюцинація — **упевнено сформульована хибна відповідь ШІ.
- **Ітерація промпта — **уточнення запиту за отриманим результатом.
- **Знеособлення даних — **видалення чутливих ознак перед обробкою.
