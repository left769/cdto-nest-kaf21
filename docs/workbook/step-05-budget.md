## Навіщо

Бюджет показує, у що обійдеться проєкт, а аналіз відхилень — чи вкладається команда в план. Рахуйте в **людино-годинах**: це не потребує реальних цін і краще підходить для навчального проєкту.

**На вході:** WBS і Гант (крок 2), резерв часу під ризики (крок 4).

## Умовні фактичні дані для аналізу відхилень

Однакові для всіх команд: **на середину проєкту** заплановано виконати 50% обсягу, фактично виконано (освоєно) 45%, а витрачено 55% бюджету. Переведіть ці частки в години свого бюджету й зробіть висновок.

## Підказки

| Поле | Як заповнити | Типова помилка |
| --- | --- | --- |
| Робочі пакети | Візьміть пакети рівня 2 з WBS; оцінюйте кожен окремо. | Бюджет «однією цифрою» згори. |
| Метод оцінки | Аналогічний, параметричний, триточковий — вкажіть, яким користувалися. | Оцінка без пояснення, звідки цифра. |
| CAPEX / OPEX | Створення — CAPEX, супровід і ліцензії — OPEX. Супровід рахуйте окремо. | Забути про вартість володіння. |
| Резерв | 10–15% під ідентифіковані ризики; згадайте EMV з кроку 4. | Резерв без прив’язки до ризиків. |
| Висновок | CPI < 1 — перевитрата, SPI < 1 — відставання; EAC — прогноз підсумку. | Порахувати індекси, але не зробити висновку. |

## Чек-лист самоперевірки

- Бюджет побудовано знизу-вгору за пакетами WBS, для кожного вказано метод оцінки.
- Розрізнено CAPEX і OPEX; супровід пораховано окремо.
- Резерв обґрунтовано ризиками з кроку 4.
- Пораховано CV, CPI, SPI, EAC за умовними даними.
- Є висновок і щонайменше 2 заходи реагування.
