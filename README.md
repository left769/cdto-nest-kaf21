# Курс CDTO — методичні матеріали

Змістова частина методичних розробок курсу підвищення кваліфікації за напрямом цифрової трансформації (CDTO). 7 тем, 28 занять. Кожне заняття — окремий файл.

Цей репозиторій — golden source контенту навчального порталу: щоб відредагувати, додати чи видалити заняття, достатньо змінити відповідний `.md`-файл у `lessons/` (зберігаючи формат перших рядків — заголовок і рядок `*Тема N: ... · Заняття M*`) і задеплоїти оновлений образ.

## Запуск застосунку

Локально (потрібен Node.js 20+):

```bash
npm install
cp .env.example .env        # і згенерувати AUTH_SECRET: openssl rand -base64 32
npx prisma migrate dev
npm run dev                 # http://localhost:3000
```

Через Docker (весь застосунок — один контейнер, SQLite зберігається у volume):

```bash
docker build -t rossogamata/cdto-nest .
docker run -d -p 3000:3000 \
  -e DATABASE_URL="file:/app/data/prod.db" \
  -e AUTH_SECRET="$(openssl rand -base64 32)" \
  -v cdto_data:/app/data \
  rossogamata/cdto-nest
```

Готовий образ публікується автоматично в Docker Hub (`rossogamata/cdto-nest`) при пуші в `main` через GitHub Actions (`.github/workflows/docker-publish.yml`) — потрібно додати секрети `DOCKERHUB_USERNAME` та `DOCKERHUB_TOKEN` у налаштуваннях репозиторію.
